ClipAsk: Highlight Text & Ask ChatGPT

Project Information

  • Project Type: Individual Project
  • AI-Assisted Development: No AI
  • GitHub: View Repository

Overview

  • ClipAsk is a lightweight Chrome extension that lets users ask ChatGPT directly from any webpage.
  • Users can highlight text or crop a visible area of the page and send it to ChatGPT instantly.
  • The extension is designed to reduce context switching by showing answers inside the current webpage.

Key Features

  • Text-to-ChatGPT using highlighted webpage text
  • Image or screen-area analysis using crop mode
  • Bottom overlay UI for displaying answers without leaving the page
  • Optional Chat Mode for keeping conversation context per domain
  • Optional Summary Mode that summarizes conversation history before the next request after the configured message count is reached
  • Domain-based memory management from the Memory tab
  • Local settings storage using Chrome storage

Tech Stack

  • Frontend: HTML, CSS, JavaScript
  • Platform: Chrome Extension Manifest V3
  • Browser APIs: contextMenus, storage, scripting, activeTab, tabs
  • AI API: OpenAI Responses API
  • Image Processing: Browser screenshot capture and canvas cropping
  • Rendering: marked.umd.js for Markdown rendering
  • Security: DOMPurify for sanitizing rendered HTML

Architecture / Workflow

Text and Image Requests:

  • Users select text or crop a visible area of a webpage and send it to ChatGPT.
  • Responses appear in an overlay on the current page.

Conversation:

  • Optional Chat Mode keeps conversation context by website domain.
  • Optional Summary Mode summarizes longer conversations to provide context for follow-up requests.

Challenges & Solutions

① Displaying answers without hiding the page

Problem:

  • A fixed overlay could cover important webpage content.

Solution:

  • Implemented a bottom overlay with scroll support.
  • Added spacing so the overlay does not permanently hide content at the bottom of the page.

② Handling image input from webpages

Problem:

  • The extension needed a simple way for users to send only a specific part of the screen.

Solution:

  • Built a crop selection UI directly on the webpage.
  • Captured the visible tab and cropped the selected area using canvas.

③ Managing conversation context

Problem:

  • Long conversations can increase token usage and cost.
  • Different websites may need separate conversation context.

Solution:

  • Stored conversations separately by domain.
  • Added optional Summary Mode to compress long conversation history.

④ Keeping user data local

Problem:

  • The extension stores sensitive settings such as the OpenAI API key.

Solution:

  • Stored the API key and settings locally using chrome.storage.local.
  • No custom backend server is used.

Result / Outcome

  • Built a Chrome extension that allows users to ask ChatGPT about selected text or cropped page areas without leaving the current website.
  • Implemented optional domain-based chat memory and summary features to support follow-up questions while controlling token usage.
  • Gained practical experience with Chrome Extension Manifest V3, browser APIs, OpenAI API integration, image cropping, and local storage.
