Overview

  • ClipAsk is a lightweight Chrome extension that lets users ask ChatGPT directly from any webpage.
  • Users can highlight text or crop a visible area of the page and send it to ChatGPT instantly.
  • The extension is designed to reduce context switching by showing answers inside the current webpage.

Key Features

  • Text-to-ChatGPT using highlighted webpage text
  • Image or screen-area analysis using crop mode
  • Bottom overlay UI for displaying answers without leaving the page
  • Optional Chat Mode for keeping conversation context per domain
  • Optional Summary Mode to reduce token usage and API cost
  • Domain-based memory management from the Memory tab
  • Local settings storage using Chrome storage

Tech Stack

  • Frontend: HTML, CSS, JavaScript
  • Platform: Chrome Extension Manifest V3
  • Browser APIs: contextMenus, storage, scripting, activeTab, tabs
  • AI API: OpenAI Responses API
  • Image Processing: Browser screenshot capture and canvas cropping
  • Rendering: marked.umd.js for Markdown rendering
  • Security: DOMPurify for sanitizing rendered HTML

Architecture / How It Works

Model Selection Flow:

  • User enters an OpenAI API Key in the Options page
  • The extension fetches available models from the OpenAI API
  • Unsupported models such as image generation, audio, realtime, transcription, and text-to-speech models are filtered out internally
  • Only usable models are shown in the model dropdowns
  • The selected model is used for text, cropped image, or summary requests

Text Request Flow:

  • User highlights text on a webpage
  • User right-clicks and selects Ask ChatGPT (selected text)
  • The extension sends the selected text to the OpenAI API
  • The response is rendered in a bottom overlay on the current page

Image Request Flow:

  • User right-clicks and selects Ask ChatGPT (crop image area)
  • User drags to select a visible area of the page
  • The extension captures the visible tab
  • The selected area is cropped using canvas
  • The cropped image is sent to the OpenAI API
  • The answer is displayed in the page overlay

Chat Mode Flow:

  • Conversation history is organized by website domain
  • The extension stores the previous response ID for each domain
  • Follow-up requests can continue the same conversation context
  • Chat Mode can be turned on or off in Settings

Summary Mode Flow:

  • Summary Mode works when Chat Mode is enabled
  • After a set number of messages, the conversation is summarized
  • The conversation ID is reset
  • The summary is reused as compact context for future messages

Settings

  • OpenAI API Key
  • Additional Prompt
  • Text Model
  • Image Model
  • Summary Model
  • Max Output Tokens
  • Chat Mode
  • Summary Mode
  • Summary Frequency

The extension fetches available models from the OpenAI API and internally filters the list before showing it in the model dropdowns. Models that are not useful for this extension, such as image generation, audio, realtime, transcription, or text-to-speech models, are not displayed. This helps users choose only models that can be used for highlighted text requests, cropped image analysis, and summarization.

All settings are stored locally in the browser using chrome.storage.local.

Permissions

Chrome Permissions:

  • contextMenus: Adds right-click options for selected text and crop mode
  • storage: Saves settings, API key, chat mode settings, and domain memory locally
  • scripting: Injects the overlay UI, crop UI, Markdown parser, and sanitizer into webpages
  • activeTab: Allows the extension to interact with the active tab after user action
  • tabs: Gets the current tab URL/domain and captures the visible tab for image cropping

Host Permissions:

  • https://*/*: Allows the extension to work on HTTPS websites
  • http://*/*: Allows the extension to work on HTTP websites
  • https://api.openai.com/*: Allows requests to the OpenAI API

Challenges & Solutions

① Displaying answers without hiding the page

Problem:

  • A fixed overlay could cover important webpage content.

Solution:

  • Implemented a bottom overlay with scroll support.
  • Added spacing so the overlay does not permanently hide content at the bottom of the page.

② Handling image input from webpages

Problem:

  • The extension needed a simple way for users to send only a specific part of the screen.

Solution:

  • Built a crop selection UI directly on the webpage.
  • Captured the visible tab and cropped the selected area using canvas.

③ Managing conversation context

Problem:

  • Long conversations can increase token usage and cost.
  • Different websites may need separate conversation context.

Solution:

  • Stored conversations separately by domain.
  • Added optional Summary Mode to compress long conversation history.

④ Keeping user data local

Problem:

  • The extension stores sensitive settings such as the OpenAI API key.

Solution:

  • Stored the API key and settings locally using chrome.storage.local.
  • No custom backend server is used.

Privacy

  • The OpenAI API key is stored locally in the browser.
  • Settings are stored using chrome.storage.local.
  • No custom backend server is used.
  • Requests are sent directly from the extension to the OpenAI API.
  • Chat history is optional and depends on Chat Mode.
  • Domain-based conversation memory can be deleted from the Memory tab.

Result / Outcome

  • Built a Chrome extension that allows users to ask ChatGPT about selected text or cropped page areas without leaving the current website.
  • Implemented optional domain-based chat memory and summary features to support follow-up questions while controlling token usage.
  • Gained practical experience with Chrome Extension Manifest V3, browser APIs, OpenAI API integration, image cropping, and local storage.
