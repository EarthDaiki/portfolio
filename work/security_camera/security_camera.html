Security Camera

Overview

  • Real-time security camera system using Raspberry Pi
  • Streams video to remote viewers via WebRTC
  • Low-latency peer-to-peer communication (no cloud dependency)

Key Features

  • Real-time video streaming (low latency)
  • WebRTC-based peer-to-peer communication
  • STUN/TURN fallback for NAT traversal
  • Secure connection using mTLS
  • Multi-client viewer support
  • Raspberry Pi camera integration

Tech Stack

  • Backend: Python (aiohttp, aiortc)
  • Streaming: WebRTC (STUN / TURN)
  • Hardware: Raspberry Pi Zero 2W + Camera
  • Media: FFmpeg / libcamera
  • Security: mTLS authentication
  • Infra: Docker (coturn), AWS

Architecture / How It Works

Flow:

  • Capture video via libcamera
  • Process and stream with WebRTC
  • Signal exchange via WebSocket (SDP / ICE)
  • P2P connection between camera and viewer
  • Fallback to TURN when direct fails

Key design:

  • Custom signaling protocol
  • Low-latency media pipeline
  • Signaling / media separation
  • Queue-based frame handling

Challenges & Solutions

① High latency on Raspberry Pi Zero 2W

Problem:

  • FFmpeg processing caused significant delay due to limited CPU

Solution:

  • Removed FFmpeg, streamed raw H264 directly
  • Reduced CPU usage and achieved low latency

② NAT traversal failure

Problem:

  • Direct P2P connection often failed across networks

Solution:

  • Implemented TURN server (coturn with Docker)
  • Configured UDP/TCP/TLS relay
  • Verified ICE candidate selection via stats

③ Secure device authentication

Problem:

  • Needed to ensure only authorized cameras can connect

Solution:

  • Implemented mTLS authentication
  • Parsed client certificate (CN) to identify camera devices

④ Separated signaling and media paths

Problem:

  • Needed a trusted client IP for IP-based access control
  • Load balancer limitations made TURN/UDP unsuitable for the same path

Solution:

  • Used AWS ALB for signaling (HTTP/WebSocket)
  • Extracted reliable client IP via X-Forwarded-For for IP-based access control
  • Allowed direct TURN server access for low-latency UDP media streaming

Result / Outcome

  • Built a fully functional low-latency security camera system capable of streaming from embedded devices over the internet.
  • Gained deep understanding of real-time communication, networking, and system optimization under hardware constraints.
