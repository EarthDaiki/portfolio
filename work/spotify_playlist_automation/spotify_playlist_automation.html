Overview

  • Developed a serverless Spotify playlist automation system using AWS Lambda.
  • Designed the application to retrieve top tracks and top artists for multiple users and update playlists automatically.
  • Implemented persistent state management with Amazon S3 for user metadata, playlist information, and Spotify OAuth cache files.
  • Enabled scheduled execution through AWS EventBridge to support fully automated periodic updates.

Key Features

  • Multi-user playlist management within a single Lambda-based workflow.
  • Automatic creation and update of playlists based on top tracks.
  • Automatic creation and update of playlists based on top artists' tracks.
  • Support for short-term, medium-term, and long-term Spotify listening ranges.
  • Persistent playlist metadata storage using Amazon S3.
  • OAuth token cache management designed for stateless serverless execution.
  • Scheduled playlist refresh through AWS EventBridge.

Tech Stack

  • Language: Python
  • Cloud Services: AWS Lambda, Amazon S3, Amazon EventBridge
  • API Integration: Spotify Web API
  • Libraries: Spotipy, boto3
  • Authentication: Spotify OAuth with cached access and refresh tokens
  • Architecture: Serverless, modular Python application design

Architecture / Workflow

Processing Flow:

  • AWS Lambda initiates the playlist update workflow.
  • User configuration and playlist metadata are loaded from Amazon S3.
  • Each user is authenticated using a Spotify OAuth cache file stored in S3.
  • Top tracks and top artists data are retrieved from the Spotify Web API.
  • Relevant playlists are created or updated based on the retrieved listening data.
  • Updated playlist URIs and state information are written back to S3.
  • The workflow is triggered automatically on a defined schedule through AWS EventBridge.

Design Considerations:

  • Separated orchestration, playlist processing, JSON state handling, and S3 operations into dedicated modules.
  • Used Amazon S3 as a persistence layer to compensate for AWS Lambda's stateless execution model.
  • Implemented reusable token cache handling to support multiple Spotify users efficiently.
  • Designed the system to scale through configuration updates rather than structural code changes.

Challenges & Solutions

① Maintaining authentication in a serverless environment

Problem:

  • AWS Lambda does not provide persistent local storage suitable for retaining Spotify OAuth cache files across executions.

Solution:

  • Implemented a custom S3-based cache handler for Spotify authentication tokens.
  • Stored each user's cache file as .cache-USER_ID in Amazon S3 to preserve authentication state between executions.

② Supporting multiple users within one automation system

Problem:

  • The application needed to support multiple users, each with separate credentials, token caches, and playlist metadata.

Solution:

  • Used a user list JSON file in Amazon S3 to drive processing dynamically.
  • Mapped credentials through environment variables such as E<USER_ID>ClientId, E<USER_ID>ClientSecret, and E<USER_ID>RedirectUrl.

③ Synchronizing playlist state across executions

Problem:

  • The Lambda function required a reliable mechanism to track which playlists already existed for each user and listening range.

Solution:

  • Stored playlist URIs in a structured playlists_info.json file in Amazon S3.
  • Initialized missing user entries automatically and updated playlist metadata after each successful run.

④ Updating playlists efficiently from external API data

Problem:

  • Playlist contents change over time, requiring efficient synchronization while operating within API and execution constraints.

Solution:

  • Compared previous and current track URIs to reduce unnecessary update operations.
  • Separated top tracks logic from top artists tracks logic to improve maintainability and simplify future extension.

Result / Outcome

  • Developed a serverless automation system that updates Spotify playlists for multiple users without manual intervention.
  • Improved operational efficiency by eliminating repetitive playlist maintenance through scheduled execution.
  • Strengthened practical experience in cloud architecture, OAuth-based authentication, state persistence, and API-driven automation.
