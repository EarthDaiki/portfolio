Challenges & Solutions

① Understanding undocumented APIs

Problem:

  • No official documentation available
  • Complex and changing request structures

Solution:

  • Analyzed network traffic using DevTools
  • Identified patterns in request/response formats
  • Reconstructed APIs manually

② Authentication and request validation

Problem:

  • Requests required specific headers, tokens, and session data

Solution:

  • Studied how authentication tokens are generated and used
  • Reproduced valid request structures

③ TLS and secure communication analysis

Problem:

  • Needed to understand how mobile apps enforce secure connections

Solution:

  • Explored TLS handshake and certificate validation behavior
  • Used controlled environments to study trust models
  • Learned how improper validation leads to vulnerabilities

④ Security and anti-abuse mechanisms

Problem:

  • Platforms implement protections against bots and misuse

Solution:

  • Observed rate limiting and request validation strategies
  • Understood importance of secure API design

⑤ Building applications using unofficial APIs

Problem:

  • No SDK or official support for interacting with these APIs
  • Requests required precise headers, tokens, and timing

Solution:

  • Implemented custom Python clients using reconstructed requests
  • Handled authentication tokens, headers, and session management
  • Built scripts to automate data retrieval and interaction with APIs

⑥ Building a data analysis tool using unofficial APIs

Problem:

  • Raw API data was complex and not structured for analysis
  • Needed a way to visualize user activity and relationships

Solution:

  • Developed a Python-based analysis tool using reconstructed API endpoints
  • Downloaded content such as posts, reels, stories, and highlights
  • Extracted and visualized location data from user posts on a map
  • Parsed story mentions and visualized relationships between users
  • Organized data into DataFrames for sorting (likes, comments, etc.)
  • Analyzed mutual vs non-mutual followers through structured datasets
  • Exported analysis results as CSV for further use

Result / Outcome

  • Developed strong understanding of how real-world systems and APIs work internally
  • Gained practical experience in network analysis and debugging
  • Learned security principles used in production systems
  • Applied insights to build more robust and secure applications
  • Built working applications that interact with real-world systems using unofficial APIs
  • Built a full data pipeline from raw API data to structured analysis and visualization
