Overview

  • Task-XP is a native task-management app for iPhone and iPad.
  • It combines structured task planning, time tracking, calendar-based navigation, progress summaries, local reminders, and optional AI-assisted task creation.
  • The app is built with SwiftUI and stores task data locally in SQLite.
  • An OpenAI API key is only required for AI-assisted task generation; core task management works offline without one.

Key Features

  • Create, edit, complete, reopen, and delete tasks with descriptions, due dates, due times, priorities, difficulty levels, estimated durations, and tags.
  • Filter tasks by Inbox, Today, Upcoming, Completed, or Tag, and sort by creation date, due date, priority, or difficulty.
  • Browse scheduled tasks in a calendar and daily timeline.
  • Start and stop work sessions while recording actual time spent.
  • Review running, overdue, and today's tasks on the Home screen.
  • View completion progress with Swift Charts.
  • Generate structured task details from natural-language prompts with the OpenAI Responses API.
  • Schedule local reminders for tasks with due dates.

Tech Stack

  • UI: SwiftUI with UIKit integration
  • State Management: Observation-based stores
  • Charts: Swift Charts
  • Persistence: SQLite3
  • Credentials: Security framework and Keychain Services
  • Notifications: UserNotifications framework
  • AI Integration: OpenAI Responses API with JSON Schema structured output
  • Platforms: iOS and iPadOS

Architecture / Workflow

App Structure:

  • SwiftUI views use task, task-list, and tag stores for application state.
  • Stores read and write task and tag records through a local SQLite database.
  • OpenAI, Keychain, and local-notification operations are handled by separate managers.

AI Task Creation:

  • The user configures an OpenAI API key and model in Settings.
  • A natural-language prompt is sent to the OpenAI Responses API when the user requests AI generation.
  • Structured task details are generated for the user to review before saving.

Privacy & Storage:

  • Tasks and tags remain in the on-device SQLite database.
  • OpenAI API keys are stored in the system Keychain and are configured not to migrate to another device.
  • Task prompts are sent to OpenAI only when the user explicitly requests AI task generation.
  • The app does not include user accounts, cloud backup, or cross-device synchronization.

Challenges & Solutions

① Keeping task management local-first

Challenge:

  • Task planning and progress tracking need to remain available without requiring an account or network connection.

Approach:

  • Store tasks and tags locally in SQLite, keeping core task-management features independent from the optional AI service.

② Protecting API credentials

Challenge:

  • AI-assisted task creation requires an API key, which should not be stored with ordinary task data.

Approach:

  • Use Keychain Services for API key storage, with device-only accessibility.

③ Making reminders respect user settings

Challenge:

  • Reminder delivery depends on operating-system notification permission and device settings.

Approach:

  • Request notification permission when scheduling is first attempted and keep task management usable if permission is denied.

Result / Outcome

  • Built a local-first native task-management prototype for iPhone and iPad.
  • The app brings task organization, calendar navigation, time tracking, progress summaries, and local reminders into one workflow.
  • AI-assisted task creation is available as an optional feature and requires an OpenAI API key.
  • The current project targets Swift 5 language mode and requires iOS or iPadOS 26.5 or later.
