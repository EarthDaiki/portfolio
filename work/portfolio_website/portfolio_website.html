Overview

  • Designed and developed a personal portfolio website to present projects, experience, contact information, and resume access.
  • Built a shared layout structure with reusable header behavior and consistent styling across pages.
  • Organized project pages to keep work descriptions, images, links, technical details, and outcomes easy to scan.

Key Features

  • Multi-page portfolio structure for Home, About, Works, and Contact pages.
  • Dynamic work card generation using JavaScript data objects.
  • Reusable detailed work page layout with image carousel and modal preview behavior.
  • Resume links opened directly from Home and About pages.
  • Consistent dark visual style with white typography, borders, SVG icons, and hover interactions.

Tech Stack

  • Design: Figma
  • Structure: HTML
  • Styling: CSS
  • Interactivity: JavaScript
  • Assets: SVG icons and local image files

Architecture / Workflow

Page Structure:

  • Root-level shared CSS and header JavaScript define common site behavior.
  • Each main page keeps its own HTML and page-specific CSS file.
  • Work cards are generated from a centralized JavaScript array in work.js.
  • Detailed work pages reuse detailed_work.css and detailed_work.js.

Design Workflow:

  • Planned the layout and page flow in Figma before implementing the site structure.
  • Translated the visual direction into HTML sections, shared CSS rules, and page-specific styling.
  • Kept the design system simple so new work pages can be added without changing the whole site.

Challenges & Solutions

① Keeping pages consistent while adding new content

Problem:

  • Multiple pages needed to share the same visual identity without duplicating every layout decision.

Solution:

  • Used shared root styles and a generated header while keeping page-specific CSS separate.

② Making the Works page easy to extend

Problem:

  • Adding a new project manually in HTML would make the Works page harder to maintain over time.

Solution:

  • Stored project card information in JavaScript and generated the card markup dynamically.

③ Presenting project details in a repeatable format

Problem:

  • Each project needed enough structure to explain links, features, tools, workflow, and outcomes clearly.

Solution:

  • Created a consistent detailed page format with Overview, Key Features, Tech Stack, Architecture, Challenges, and Result sections.

Result / Outcome

  • Built a portfolio website that can grow as new projects and design materials are added.
  • Created a structure that separates HTML, CSS, and JavaScript responsibilities clearly.
  • Added a dedicated Figma design link to show the planning and visual design process.
